# মিডিয়া রিকোয়ারমেন্ট

সাইটে কোনো কৃত্রিম বা বানানো প্রোডাক্ট স্ক্রিনশট ব্যবহার করা হয়নি। ছবি না থাকলে
নিরপেক্ষ প্লেসহোল্ডার দেখানো হয়। নিচের তালিকাটি মালিকের সরবরাহ করার জন্য।

## অগ্রাধিকার ১ — লঞ্চের আগে

| ছবি | মাপ | ফরম্যাট | কোথায় |
|---|---|---|---|
| মালিকের প্রতিকৃতি | ৮০০×৮০০ | WebP/JPG | পরিচিতি, লেখক কার্ড, Person schema |
| NB Engineering Tools কভার | ১২০০×৬৩০ | WebP/PNG | প্রোডাক্ট পাতা, OG কার্ড |
| Ribbon-এ NB ট্যাব | ১৬০০ চওড়া | PNG | ইঞ্জিনিয়ারিং টুলস পাতা |
| Classic pull-down মেনু | ১৬০০ চওড়া | PNG | একই |

## অগ্রাধিকার ২ — কনটেন্টের সঙ্গে

| ছবি | মাপ | কোথায় |
|---|---|---|
| প্রতিটি আর্টিকেলের কভার | ১২০০×৬৩০ | ব্লগ কার্ড ও শেয়ার কার্ড |
| আর্টিকেলের মূল ডায়াগ্রাম | ১৬০০ চওড়া | লেখার ভেতরে |
| প্রতিটি ফিচার গ্রুপের স্ক্রিনশট | ১৬০০ চওড়া | প্রোডাক্ট পাতা |
| কোর্স কভার | ১২০০×৬৩০ | কোর্স তালিকা ও পাতা |

## নিয়ম

- **প্রতিটি ছবির alt টেক্সট বাধ্যতামূলক।** অ্যাডমিনের মিডিয়া তালিকায় alt না
  থাকলে লাল করে দেখানো হয়।
- ডায়াগ্রাম **মৌলিক** হতে হবে। কপিরাইটযুক্ত কোড বা স্ট্যান্ডার্ডের টেবিল/চিত্র
  কপি করা যাবে না।
- স্ক্রিনশটে কোনো লাইসেন্স কোড, Machine ID, গ্রাহকের নাম বা ফাইলপথ দেখা যাবে না।
- আপলোডের আগে ছবি রিসাইজ করুন; `next/image` AVIF/WebP তৈরি করে, কিন্তু ৫ MB
  সোর্স আপলোড করলে স্টোরেজ ও অপ্টিমাইজেশন খরচ বাড়ে।
- অনুপাত ১৬:৯ (কার্ড) বা ১২০০×৬৩০ (শেয়ার কার্ড) রাখলে কোথাও crop হবে না।

## গ্রহণযোগ্য ফরম্যাট

`image/jpeg`, `image/png`, `image/webp`, `image/avif`, `image/svg+xml`,
`application/pdf` — সর্বোচ্চ ২০ MB। MIME টাইপ ও প্রকৃত এক্সটেনশন দুটোই সার্ভারে
যাচাই করা হয় এবং ফাইলটি জেনারেট করা নামে সংরক্ষিত হয়।
