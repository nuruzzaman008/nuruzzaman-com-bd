## এক বাক্যে

লোড পাথ হলো সেই ধারাবাহিক পথ, যেটি ধরে একটি ভার তার উৎপত্তিস্থল থেকে মাটি
পর্যন্ত পৌঁছায়। পথের একটি অংশও অনুপস্থিত থাকলে কাঠামো দাঁড়ায় না।

## একটি সাধারণ ভবনের পথ

```
মানুষ ও আসবাব (live load)
        ↓
      স্ল্যাব
        ↓
      বিম
        ↓
      কলাম
        ↓
     ফুটিং
        ↓
      মাটি
```

প্রতিটি তীরচিহ্নে ভার এক উপাদান থেকে পরের উপাদানে হস্তান্তরিত হয়। প্রতিটি
হস্তান্তরের জায়গাই একটি সম্ভাব্য দুর্বল বিন্দু — তাই সংযোগস্থল (joint,
bearing, anchorage) ডিজাইনে আলাদা মনোযোগ পায়।

## দুটি আলাদা পথ

প্রতিটি ভবনে অন্তত **দুটি** লোড পাথ থাকে:

1. **Gravity path** — উপর থেকে নিচে। স্ল্যাব → বিম → কলাম → ফুটিং।
2. **Lateral path** — পাশ থেকে। বাতাস বা ভূমিকম্পের বল দেয়াল/ফ্রেম হয়ে
   ফাউন্ডেশনে যায়।

একটি ভবনে gravity path নিখুঁত হয়েও lateral path অসম্পূর্ণ থাকতে পারে — যেমন
নিচতলায় দেয়াল সরিয়ে দোকান বানালে। এটি বাংলাদেশে বহুতল ভবনের একটি পরিচিত ঝুঁকি।

## এই কোর্সে যা করব

প্রতিটি লেসনে একটি নির্দিষ্ট ধাপ ধরে সংখ্যা বসিয়ে হিসাব করব, এবং প্রতিবার
বলে দেব কী ধরে নেওয়া হয়েছে।

## সংজ্ঞা

- **Dead load (D)** — স্থায়ী ও অপরিবর্তনীয়: কাঠামোর নিজের ওজন, ফিনিশ, স্থায়ী
  partition, ছাদের waterproofing।
- **Live load (L)** — পরিবর্তনশীল: মানুষ, আসবাব, সরঞ্জাম, সংরক্ষিত মালামাল।

## কেন আলাদা রাখতে হয়

দুটির **অনিশ্চয়তা আলাদা**। Dead load মোটামুটি ভালোভাবে অনুমান করা যায় —
কংক্রিটের ঘনত্ব জানা, পুরুত্ব ড্রয়িংয়ে আছে। Live load অনেক বেশি অনিশ্চিত —
কে কী রাখবে তা আগে থেকে বলা যায় না।

তাই load combination-এ live load-এর factor বেশি (১.৬ বনাম ১.২)। এটি খেয়ালখুশি
নয়, অনিশ্চয়তার পরিমাপ।

## একটি তলার dead load ভাঙা

১৭৫ mm স্ল্যাব, সাধারণ আবাসিক ফিনিশ:

| উপাদান | হিসাব | kPa |
| --- | --- | --- |
| স্ল্যাব | ০.১৭৫ × ২৪ | ৪.২০ |
| Floor finish (৫০ mm) | ০.০৫ × ২১ | ১.০৫ |
| Ceiling plaster (১৫ mm) | ০.০১৫ × ২০ | ০.৩০ |
| Partition allowance | — | ১.০০ |
| **মোট D** | | **৬.৫৫ kPa** |

## ব্যবহৃত অ্যাজাম্পশন

- কংক্রিটের unit weight ২৪ kN/m³ (reinforced)।
- Partition allowance ১.০ kPa — হালকা partition ধরে। ইটের দেয়াল হলে
  আলাদা করে রেখা বরাবর লোড হিসেবে ধরতে হবে, distributed হিসেবে নয়।

## সীমাবদ্ধতা

Live load-এর মান কোড থেকে নিতে হয়, ব্যবহারভেদে ভিন্ন — আবাসিক, অফিস,
বিদ্যালয়, গুদাম সবার জন্য আলাদা। প্রকল্পে প্রযোজ্য কোড এডিশনের তালিকাই ভিত্তি।

## নিয়মটি

একটি সহায়ক উপাদান (বিম বা কলাম) তার দুই পাশের span-এর **অর্ধেক করে** ভার নেয়।
নিয়মিত গ্রিডে এটি যথেষ্ট নির্ভুল।

## বিমের ক্ষেত্রে

৫.০ m span-এর দুটি সমান্তরাল বিমের মাঝের বিমটি:

```
tributary প্রস্থ = 5.0/2 + 5.0/2 = 5.0 m  → না, ভুল
```

সতর্কতা: এখানে ৫.০ m হলো **বিমের মধ্যবর্তী দূরত্ব**, span নয়। বিম দুটির
ব্যবধান ৩.০ m হলে:

```
tributary প্রস্থ = 3.0/2 + 3.0/2 = 3.0 m
w = 6.55 kPa × 3.0 m = 19.65 kN/m
```

## কলামের ক্ষেত্রে

গ্রিড ৫.০ m × ৬.০ m, অভ্যন্তরীণ কলাম:

```
A = (5.0/2 + 5.0/2) × (6.0/2 + 6.0/2) = 5.0 × 6.0 = 30 m²
```

প্রান্তের কলামে এক দিকে অর্ধেক থাকে না:

```
প্রান্ত কলাম:  A = (5.0/2) × 6.0 = 15 m²
কোণার কলাম:   A = (5.0/2) × (6.0/2) = 7.5 m²
```

অর্থাৎ কোণার কলামে অভ্যন্তরীণের **এক-চতুর্থাংশ** ভার — কিন্তু সেখানেই
lateral load থেকে সবচেয়ে বেশি moment আসে।

## কোথায় এই পদ্ধতি ভাঙে

- অসম span (একদিকে ৩ m, অন্যদিকে ৭ m)
- Cantilever
- Transfer beam বা flat plate
- বড় opening বা lift core-এর পাশে

এসব ক্ষেত্রে continuous beam analysis বা model থেকে reaction নিতে হবে।

## মূল কথা

ভিন্ন combination ভিন্ন member-কে সবচেয়ে বেশি চাপে ফেলে। একটি চালিয়ে থেমে
গেলে অন্যটির নিয়ন্ত্রক অবস্থা ধরা পড়ে না।

## একটি cantilever ছাদের উদাহরণ

২.০ m cantilever, `D` = ৫.০ kPa, `L` = ১.০ kPa, uplift wind `W` = −২.৫ kPa।

### Gravity combination

```
w_u = 1.2 × 5.0 + 1.6 × 1.0 = 6.0 + 1.6 = 7.6 kPa (নিচের দিকে)
M_u = 7.6 × 2.0² / 2 = 15.2 kN·m/m  → উপরে টান, top rod লাগবে
```

### Uplift combination

```
w_u = 0.9 × 5.0 − 1.0 × 2.5 = 4.5 − 2.5 = 2.0 kPa (এখনো নিচের দিকে)
```

এখানে uplift নিয়ন্ত্রক হয়নি। কিন্তু ছাদ হালকা হলে (`D` = ১.৫ kPa):

```
w_u = 0.9 × 1.5 − 2.5 = 1.35 − 2.5 = −1.15 kPa (উপরের দিকে)
M_u = 1.15 × 2.0² / 2 = 2.3 kN·m/m  → নিচে টান, bottom rod লাগবে
```

অর্থাৎ হালকা ছাদে rod **উল্টো দিকে** লাগবে। শুধু gravity combination চালালে
এটি কখনো ধরা পড়ত না।

## যা মনে রাখতে হবে

`0.9 D` combination-টি dead load কম হওয়ার সম্ভাবনা পরীক্ষা করে। হালকা কাঠামো,
বড় cantilever, বা signage/canopy-তে এটি প্রায়ই নিয়ন্ত্রক।

## ১ — মোট ওজন মিলিয়ে দেখুন

Model-এর base reaction-এর যোগফল হাতে হিসাব করা মোট ওজনের কাছাকাছি হওয়া উচিত।

```
হাতে: 6.55 kPa × মোট floor area × তলা সংখ্যা
```

১০%-এর বেশি পার্থক্য হলে কিছু একটা ভুল — সম্ভবত self weight দুইবার ধরা হয়েছে,
বা একটি লোড কেসই প্রয়োগ হয়নি।

## ২ — একটি কলামের reaction হাতে মেলান

Tributary area পদ্ধতিতে একটি অভ্যন্তরীণ কলামের লোড বের করে model-এর সাথে
মেলান। নিয়মিত গ্রিডে ১৫%-এর মধ্যে থাকা উচিত।

## ৩ — Deflection যুক্তিসঙ্গত কি না দেখুন

সাধারণ ভবনের বিমে service deflection `span/300` থেকে `span/500`-এর মধ্যে
থাকে। ৫ m span-এ ৫০ mm এলে model-এ support condition বা material property
ভুল আছে।

## কেন এটি জরুরি

Analysis software ভুল ইনপুটেও সুন্দর ফলাফল দেয়। সংখ্যাটি যুক্তিসঙ্গত কি না
সেটি বলার দায়িত্ব প্রকৌশলীর, সফটওয়্যারের নয়।

## নিয়ম

ফুটিংয়ের ক্ষেত্রফল **service load** দিয়ে বের হয়, factored load দিয়ে নয় —
কারণ allowable bearing capacity নিজেই একটি service-level মান।

## হিসাব

- `D` = ৬৫০ kN, `L` = ২২০ kN
- `q_a` = ১৫০ kPa
- ফুটিংয়ের নিচের গভীরতা `D_f` = ১.৫ m

### নিট bearing capacity

ফুটিং ও উপরের মাটির গড় unit weight ২০ kN/m³ ধরে:

```
q_net = 150 − 20 × 1.5 = 150 − 30 = 120 kPa
```

### প্রয়োজনীয় ক্ষেত্রফল

```
A = (650 + 220) / 120 = 870 / 120 = 7.25 m²
বর্গাকার ধরলে B = √7.25 = 2.69 m → 2.7 m
```

## কেন `q_net` ব্যবহার

ফুটিং বসানোর পর ওই গভীরতার মাটি সরে যায় এবং তার জায়গায় কংক্রিট ও ব্যাকফিল
আসে। যে চাপ আগে থেকেই ছিল, সেটুকু নতুন করে যোগ হয় না — তাই বাদ দিতে হয়।
এই ধাপ বাদ দিলে ফুটিং ছোট হয়ে যায়।

## অ্যাজাম্পশন

- Concentric load, কোনো moment নেই।
- ফুটিং ও ব্যাকফিলের গড় unit weight ২০ kN/m³।
- `q_a` মাটির রিপোর্ট থেকে, settlement সীমা ধরে দেওয়া।

## পরের ধাপ

এই ২.৭ m সাইজ নিয়ে পরের লেসনে punching shear চেক করব — সেখানেই গভীরতা
নির্ধারিত হবে।

## দুটি shear চেক

| চেক | Critical section | সাধারণত |
| --- | --- | --- |
| Two-way (punching) | কলামের মুখ থেকে `d/2` | প্রায় সবসময় নিয়ন্ত্রক |
| One-way (beam) | কলামের মুখ থেকে `d` | কম নিয়ন্ত্রক |

## Punching shear

আগের লেসনের ফুটিং: ২.৭ m বর্গ, কলাম ৪০০ × ৪০০ mm, `f'c` = ২৫ MPa।
`P_u = 1.2 × 650 + 1.6 × 220 = 780 + 352 = 1132 kN`।

`d = 450` mm ধরে শুরু করি:

```
b₀ = 4 × (400 + 450) = 3400 mm
q_u = 1132 / (2.7 × 2.7) = 1132 / 7.29 = 155 kPa
ভেতরের ক্ষেত্রফল = 0.85² = 0.7225 m²
V_u = 155 × (7.29 − 0.7225) = 155 × 6.5675 ≈ 1018 kN

φV_c = 0.75 × 0.33 × √25 × 3400 × 450 / 1000 ≈ 1893 kN
```

`1018 < 1893` — অনেক বেশি নিরাপদ। তাই `d` কমিয়ে দেখা যাক, `d = 300` mm:

```
b₀ = 4 × 700 = 2800 mm
ভেতরের ক্ষেত্রফল = 0.7² = 0.49 m²
V_u = 155 × (7.29 − 0.49) = 155 × 6.80 ≈ 1054 kN
φV_c = 0.75 × 1.65 × 2800 × 300 / 1000 ≈ 1040 kN
```

`1054 > 1040` — সামান্য বেশি, চলবে না। তাই `d = 320` mm নেওয়া যায়:

```
b₀ = 4 × 720 = 2880 mm
φV_c = 0.75 × 1.65 × 2880 × 320 / 1000 ≈ 1140 kN  ✔
```

## মোট পুরুত্ব

```
h = d + cover + bar ব্যাসার্ধ = 320 + 75 + 8 ≈ 403 mm → 425 mm
```

মাটির সাথে সংস্পর্শে cover ৭৫ mm।

## কেন rod বাড়িয়ে shear সমাধান হয় না

Punching shear-এ কংক্রিটই মূলত ভার নেয়। Flexural rod বাড়ালে shear capacity
প্রায় বাড়েই না — গভীরতা বাড়ানোই কার্যকর পথ।

## Critical section

Flexure-এর critical section **কলামের মুখে**, ফুটিংয়ের কেন্দ্রে নয়।

## হিসাব

- ফুটিং ২.৭ m বর্গ, কলাম ৪০০ mm
- `q_u` = ১৫৫ kPa, `d` = ৩২০ mm
- `f'c` = ২৫ MPa, `f_y` = ৪২০ MPa

### Cantilever দৈর্ঘ্য

```
l = (2.7 − 0.4) / 2 = 1.15 m
```

### প্রতি মিটার প্রস্থে moment

```
M_u = q_u × l² / 2 = 155 × 1.15² / 2 = 155 × 0.661 = 102.5 kN·m/m
```

### প্রয়োজনীয় ক্ষেত্রফল

আনুমানিক `jd ≈ 0.95 d` ধরে প্রথম চেষ্টা:

```
A_s = M_u / (φ × f_y × 0.95d)
    = 102.5 × 10⁶ / (0.9 × 420 × 0.95 × 320)
    = 102.5 × 10⁶ / 114,912
    ≈ 892 mm²/m
```

### Minimum steel

ফুটিংয়ে shrinkage ও temperature-এর ন্যূনতম:

```
A_s,min = 0.0018 × 1000 × 425 = 765 mm²/m
```

892 > 765, তাই flexure নিয়ন্ত্রক।

### Bar নির্বাচন

```
১৬ mm bar-এর ক্ষেত্রফল = 201 mm²
ব্যবধান = 201 / 892 × 1000 = 225 mm
→ 16 mm @ 200 mm c/c (দুই দিকেই)
```

সরবরাহকৃত: `201 / 0.200 = 1005 mm²/m` ✔

## অ্যাজাম্পশন ও সীমাবদ্ধতা

- `jd = 0.95d` একটি প্রথম-চেষ্টা অনুমান; চূড়ান্ত হিসাবে `a` বের করে যাচাই করুন।
- বর্গাকার ফুটিংয়ে দুই দিকে সমান rod। আয়তাকার হলে ছোট দিকের rod-এর একটি অংশ
  মাঝের ব্যান্ডে ঘন করে দিতে হয়।
- Development length যাচাই করতে হবে: কলামের মুখ থেকে rod-এর প্রান্ত পর্যন্ত
  দূরত্ব `l_d`-এর চেয়ে বেশি হতে হবে।

1. **কেন্দ্র থেকে কেন্দ্র নয়, পরিষ্কার মাপ** — যেখানে স্পেসিফিকেশন তাই বলে।

## নীতি

একটি ছাদে স্ল্যাব ও বিম আলাদা করে মাপলে বিমের উপরের অংশ দুইবার গোনা হয়।
একটি স্পষ্ট নিয়ম ঠিক করুন এবং পুরো প্রকল্পে সেটিই মানুন।

## প্রচলিত নিয়ম

**স্ল্যাব পুরো ক্ষেত্রফলে ধরুন, বিম শুধু স্ল্যাবের নিচের অংশটুকু।**

## উদাহরণ

একটি ৮.০ m × ৫.০ m ছাদ:

- স্ল্যাব ১৭৫ mm
- চারদিকে বিম ৩০০ × ৪৫০ mm (মোট গভীরতা, স্ল্যাব সহ)

### স্ল্যাব

```
V = 8.0 × 5.0 × 0.175 = 7.00 m³
```

### বিম (স্ল্যাবের নিচের অংশ)

```
নিচের গভীরতা = 0.450 − 0.175 = 0.275 m
পরিধি বরাবর দৈর্ঘ্য = 2 × (8.0 + 5.0) − 4 × 0.300 = 26.0 − 1.2 = 24.8 m
V = 24.8 × 0.300 × 0.275 = 2.05 m³
```

কোণায় বিমের ছেদ বাদ দিতে `4 × 0.300` কমানো হয়েছে।

### মোট

```
7.00 + 2.05 = 9.05 m³
```

## যাচাই

গড় পুরুত্ব দিয়ে মিলিয়ে দেখুন:

```
9.05 / (8.0 × 5.0) = 0.226 m গড়
```

১৭৫ mm স্ল্যাব + বিম মিলিয়ে ২২৬ mm গড় — যুক্তিসঙ্গত। ৩০০ mm-এর বেশি এলে
কোথাও দুইবার গোনা হয়েছে।

## পার্থক্য

- **Nominal mix** — নির্দিষ্ট অনুপাত (১:২:৪, ১:১.৫:৩)। উপকরণের মান যাচাই না
  করেই প্রয়োগ করা হয়।
- **Design mix** — লক্ষ্য strength ঠিক করে, ব্যবহৃত সিমেন্ট, বালু ও খোয়ার
  প্রকৃত বৈশিষ্ট্য দিয়ে অনুপাত হিসাব করা হয় এবং trial batch দিয়ে প্রমাণ করা হয়।

## কেন এটি গুরুত্বপূর্ণ

১:২:৪ মিক্স থেকে কত strength আসবে তা **আগে থেকে বলা যায় না**। একই অনুপাতে
ভালো খোয়া ও পরিষ্কার বালু দিয়ে ৩০ MPa আসতে পারে, আবার নরম খোয়া ও কাদামাখা
বালু দিয়ে ১৫ MPa-ও হতে পারে।

তাই কাঠামোগত কংক্রিটে **স্পেসিফিকেশনে `f'c` লেখা থাকে, অনুপাত নয়** — এবং
সেটি প্রমাণ হয় কিউব টেস্টে।

## Water-cement ratio

Strength-এর একক সবচেয়ে বড় নিয়ন্ত্রক হলো w/c অনুপাত। পানি বাড়ালে কাজ করা সহজ
হয়, কিন্তু strength দ্রুত কমে। মোটামুটি:

| w/c | আপেক্ষিক strength |
| --- | --- |
| ০.৪০ | সবচেয়ে বেশি |
| ০.৫০ | প্রায় ৭৫% |
| ০.৬০ | প্রায় ৫৫% |

এগুলো আপেক্ষিক প্রবণতা দেখানোর জন্য, নির্দিষ্ট মান নয়।

## সাইটে করণীয়

মিক্সারে পানি ঢালার আগে **বালুর আর্দ্রতা** ধরুন। ভেজা বালুতে ইতিমধ্যেই পানি
আছে; একই পরিমাণ পানি যোগ করলে প্রকৃত w/c বেড়ে যায়।

## Slump কী মাপে

Slump মাপে **workability** — কংক্রিট কতটা সহজে বসে ও compact হয়। এটি
**strength মাপে না**।

## পদ্ধতি সংক্ষেপে

১. ৩০০ mm উঁচু কোন ভিজিয়ে সমতলে বসান।
২. তিন স্তরে ভরুন, প্রতি স্তরে ২৫ বার rod দিয়ে খোঁচান।
৩. উপর সমান করে ৫–১০ সেকেন্ডে সোজা উপরে তুলুন।
৪. কোনের উচ্চতা ও কংক্রিটের সর্বোচ্চ বিন্দুর পার্থক্য মাপুন।

## প্রচলিত পরিসর

| কাজ | Slump (mm) |
| --- | --- |
| ফুটিং ও ভারী section | ২৫–৭৫ |
| স্ল্যাব ও বিম | ৫০–১০০ |
| কলাম ও পাতলা section | ৭৫–১২৫ |
| Pump দিয়ে ঢালাই | ১০০–১৫০ |

## Slump বেশি এলে কী বোঝায়

সাধারণত **পানি বেশি**। তার মানে w/c বেড়েছে, অর্থাৎ strength কমবে। Slump
বেশি এলে সেই ট্রাক ফিরিয়ে দেওয়ার সিদ্ধান্ত নিতে হতে পারে — পরে কিউব ফেল
করার চেয়ে তখনই ধরা ভালো।

## যা slump বলে না

- চূড়ান্ত strength
- সিমেন্টের পরিমাণ সঠিক কি না
- Aggregate-এর gradation ঠিক আছে কি না
- Admixture ঠিকমতো মিশেছে কি না

Superplasticizer ব্যবহার করলে কম w/c-তেও উঁচু slump আসে — তখন slump দিয়ে
পানির পরিমাণ অনুমান করা যায় না।

- **Cover block** — মর্টার বা প্লাস্টিকের, একই grade-এর। ইটের টুকরো নয়:

- **সংখ্যা** — প্রতি বর্গমিটারে অন্তত ৪টি; বিমের পাশে প্রতি ১ m-এ একটি।

## কেন কিউরিং

সিমেন্টের hydration চলতে **পানি লাগে**। কংক্রিট শুকিয়ে গেলে hydration থেমে
যায় এবং strength বাড়া বন্ধ হয়ে যায় — শুকনো কংক্রিট আর কখনো তার সম্ভাব্য
strength-এ পৌঁছায় না।

## সময়

| অবস্থা | ন্যূনতম কিউরিং |
| --- | --- |
| সাধারণ OPC, মাঝারি আবহাওয়া | ৭ দিন |
| গরম ও শুষ্ক আবহাওয়া | ১০–১৪ দিন |
| Blended cement (PPC/PCC) | ১০–১৪ দিন |
| জল ধারণকারী কাঠামো | ১৪ দিন বা বেশি |

## পদ্ধতি

- **Ponding** — স্ল্যাবে সবচেয়ে কার্যকর। বালু দিয়ে বাঁধ দিয়ে পানি জমিয়ে রাখা।
- **ভেজা চট** — কলাম ও বিমে। **শুকিয়ে যেতে দেওয়া চলবে না** — শুকনো চট
  কংক্রিট থেকে পানি টেনে নেয়, উপকারের বদলে ক্ষতি করে।
- **Curing compound** — যেখানে পানি দেওয়া কঠিন। একবার প্রয়োগ, কিন্তু
  পরবর্তী প্লাস্টার বা টাইলসের বন্ধনে প্রভাব ফেলতে পারে।

## প্রথম ২৪ ঘণ্টা

সবচেয়ে গুরুত্বপূর্ণ। ঢালাইয়ের পর পৃষ্ঠ শক্ত হওয়ামাত্র কিউরিং শুরু করুন।
গরমে ঢালাই করলে ঢালাইয়ের কয়েক ঘণ্টার মধ্যেই পৃষ্ঠ ফাটতে পারে (plastic
shrinkage crack) — তখন ভেজা চট বা fog spray দিয়ে ঢেকে দিন।

## বাস্তব প্রভাব

৭ দিন কিউরিং করা কংক্রিট এবং একেবারে কিউরিং না করা কংক্রিটের মধ্যে ২৮ দিনের
strength-এ উল্লেখযোগ্য পার্থক্য হয়। প্রকৃত পার্থক্য আবহাওয়া, সিমেন্টের ধরন ও
section-এর আকারের উপর নির্ভর করে — তাই এখানে কোনো নির্দিষ্ট শতাংশ দাবি করা
হচ্ছে না। নিজের সাইটে দুই সেট কিউব দিয়ে তুলনা করে দেখলে সংখ্যাটি নিজেই পাবেন।

## সূত্র

```
Q_ult = Q_s + Q_b
Q_all = Q_ult / FS
```

## উদাহরণ

আগের লেসনের মাটিতে একটি bored pile: `D` = ০.৬ m, তলা ২০ m গভীরে।

### Skin friction — স্তরভিত্তিক

উপরের ২.৫ m বাদ (নরম কাদা)। Bored pile-এ `f_s ≈ 2 N₆₀` (kPa):

```
2.5–8.0 m,  N = 7  → f_s = 14 kPa,  দৈর্ঘ্য 5.5 m
8.0–16.0 m, N = 18 → f_s = 36 kPa,  দৈর্ঘ্য 8.0 m
16.0–20.0 m, N = 35 → f_s = 70 kPa, দৈর্ঘ্য 4.0 m

পরিধি = π × 0.6 = 1.885 m

Q_s = 1.885 × (14×5.5 + 36×8.0 + 70×4.0)
    = 1.885 × (77 + 288 + 280)
    = 1.885 × 645 ≈ 1216 kN
```

### End bearing

```
q_b = 90 × 35 = 3150 kPa
তলার ক্ষেত্রফল = π × 0.6²/4 = 0.283 m²
Q_b = 3150 × 0.283 ≈ 891 kN
```

### মোট

```
Q_ult = 1216 + 891 = 2107 kN
Q_all = 2107 / 2.5 ≈ 843 kN
```

## লক্ষ্য করার বিষয়

ঘর্ষণ থেকে এসেছে ৫৮%, ঠেকা থেকে ৪২%। পাইল আরও লম্বা করলে ঘর্ষণের অংশ বাড়ে
কিন্তু end bearing একই থাকে — তাই দৈর্ঘ্য বাড়ানো একটি কার্যকর পথ, যদি
নিচে ভালো স্তর থাকে।

## সীমাবদ্ধতা

`f_s = 2N` ও `q_b = 90N` bored pile-এর জন্য প্রচলিত রক্ষণশীল correlation।
Driven pile-এ মান অনেক বেশি। নির্মাণ পদ্ধতি (boring fluid, cleaning,
concreting) প্রকৃত ঘর্ষণ যথেষ্ট বদলে দেয় — **load test ছাড়া এই সংখ্যা
চূড়ান্ত ধরা যাবে না।**

## কেন যোগফল নয়

কাছাকাছি পাইলগুলো একই মাটি ভাগ করে নেয়। তাই n টি পাইলের group-এর ক্ষমতা
এককের n গুণ নয়, কিছুটা কম।

```
Q_group = η × n × Q_single
```

`η` = group efficiency, সাধারণত ০.৭–১.০।

## ব্যবধানের নিয়ম

কেন্দ্র থেকে কেন্দ্র ব্যবধান সাধারণত `2.5D` থেকে `3D`। কম হলে efficiency
দ্রুত কমে এবং নির্মাণে একটি পাইল আরেকটির ক্ষতি করতে পারে।

০.৬ m ব্যাসের পাইলে:

```
ন্যূনতম ব্যবধান = 2.5 × 0.6 = 1.5 m
প্রচলিত        = 3.0 × 0.6 = 1.8 m
```

## চার-পাইলের group

```
Q_single = 843 kN
n = 4, ব্যবধান 3D ধরে η ≈ 0.9

Q_group = 0.9 × 4 × 843 ≈ 3035 kN
```

## Block failure

কাদামাটিতে group পুরোটা একটি বড় ব্লক হয়ে নেমে যেতে পারে। তখন ক্ষমতা হিসাব

## গভীরতা কী ঠিক করে

তিনটি চেক, যার মধ্যে সবচেয়ে বড়টি নিয়ন্ত্রক:

1. কলামের চারপাশে **punching shear**
2. একটি পাইলের চারপাশে **punching shear**
3. **One-way shear**, কলামের মুখ থেকে `d` দূরে

এছাড়া পাইলের dowel-এর development length-ও ন্যূনতম গভীরতা ঠিক করে দেয়।

## চার-পাইলের cap

- পাইল ০.৬ m ব্যাস, ব্যবধান ১.৮ m
- Cap: ২.৮ m × ২.৮ m
- কলাম ৫০০ × ৫০০ mm
- `P_u` = ২৮০০ kN → প্রতি পাইলে ৭০০ kN

### Truss ধারণা

Cap গভীর হলে কলাম থেকে পাইলে ভার সরাসরি কাত হয়ে যায় (strut-and-tie)। এই
আচরণ ধরার শর্ত মোটামুটি:

```
d ≥ পাইল কেন্দ্র থেকে কলামের মুখ পর্যন্ত দূরত্ব
```

```
দূরত্ব = 1.8/2 − 0.5/2 = 0.9 − 0.25 = 0.65 m
→ d ≈ 650 mm, h ≈ 650 + 75 + 25 ≈ 750 mm
```

### নিচের rod

Truss-এ নিচের rod হলো tie। আনুমানিক টান:

```
T = (দুই পাইলের ভার) × (আনুভূমিক দূরত্ব) / (2 × d)
  = 1400 × 0.9 / (2 × 0.65) ≈ 969 kN

A_s = 969 × 10³ / (0.9 × 420) ≈ 2564 mm²
→ 9 টি 20 mm bar (2827 mm²) প্রতি দিকে
```

## গুরুত্বপূর্ণ ডিটেইল

- নিচের rod **পাইলের উপর দিয়ে সোজা যাবে** এবং প্রান্তে hook থাকবে —
  tie ছিঁড়ে গেলে পুরো truss ভেঙে পড়ে।
- পাইলের মাথা cap-এ অন্তত ৭৫–১০০ mm ঢুকবে।
- পাইলের reinforcement cap-এ development length পর্যন্ত ঢুকবে।

## সীমাবদ্ধতা

উপরের truss হিসাব একটি সরলীকৃত রূপ। প্রকৃত ডিজাইনে strut-এর প্রস্থ ও nodal
zone-এর চাপও যাচাই করতে হয়, এবং প্রযোজ্য কোডের strut-and-tie বিধান অনুসরণ
করতে হয়।

## মূল ধারণা

বিম বাঁকলে উপরের অংশ চাপে (compression) আর নিচের অংশ টানে (tension) পড়ে।
কংক্রিট চাপ ভালো নেয়, টান প্রায় নেয় না — তাই টানের দিকে rod দিতে হয়।

## নিরপেক্ষ অক্ষ

উপরের চাপ আর নিচের টানের মাঝখানে একটি তল থাকে যেখানে stress শূন্য — এটিই
neutral axis। বিমের capacity নির্ভর করে এই অক্ষের দুই পাশে কতটা লিভার-আর্ম
পাওয়া যাচ্ছে তার উপর।

```
C = 0.85 f'c × a × b        (কংক্রিটের চাপ বল)
T = A_s × f_y                (rod-এর টান বল)
C = T  →  a = A_s f_y / (0.85 f'c b)
M_n = T × (d − a/2)
```

## কোন দিকে rod

| অবস্থা | টান কোথায় | rod কোথায় |
| --- | --- | --- |
| Simply supported, mid-span | নিচে | নিচে |
| Continuous বিম, support-এ | উপরে | উপরে |
| Cantilever | উপরে | উপরে |

**সবচেয়ে সাধারণ ভুল:** continuous বিমের support-এ top rod না দেওয়া। সেখানে
hogging moment হয় এবং টান উপরে থাকে।

## এই কোর্সে যা করব

একটি বিমের সম্পূর্ণ পথ ধরে যাব — moment থেকে rod, rod থেকে stirrup, তারপর
ড্রয়িং ও schedule।

## উদাহরণ

- বিম: ৩০০ × ৫০০ mm (মোট গভীরতা)
- Cover ৪০ mm, stirrup ৮ mm, main bar ২০ mm
- `f'c` = ২৫ MPa, `f_y` = ৪২০ MPa
- `M_u` = ১৮৫ kN·m

### ধাপ ১ — effective depth

```
d = 500 − 40 − 8 − 20/2 = 442 mm
```

### ধাপ ২ — প্রয়োজনীয় A_s (প্রথম চেষ্টা)

`jd ≈ 0.9d` ধরে:

```
A_s = M_u / (φ f_y × 0.9d)
    = 185 × 10⁶ / (0.9 × 420 × 0.9 × 442)
    = 185 × 10⁶ / 150,400
    ≈ 1230 mm²
```

### ধাপ ৩ — a বের করে যাচাই

```
a = A_s f_y / (0.85 f'c b) = 1230 × 420 / (0.85 × 25 × 300) = 81 mm
M_n = A_s f_y (d − a/2) = 1230 × 420 × (442 − 40.5) / 10⁶ = 207 kN·m
φM_n = 0.9 × 207 = 186 kN·m  ≥ 185  ✔
```

### ধাপ ৪ — bar নির্বাচন

```
২০ mm bar-এর ক্ষেত্রফল = 314 mm²
সংখ্যা = 1230 / 314 = 3.9 → 4 টি
সরবরাহকৃত A_s = 1256 mm²  ✔
```

### ধাপ ৫ — ন্যূনতম ও সর্বোচ্চ যাচাই

```
A_s,min = max(1.4/f_y, √f'c/(4f_y)) × b × d
        = max(0.00333, 0.00298) × 300 × 442 = 442 mm²   ✔ (1256 > 442)
```

Tension-controlled কি না দেখতে `c = a/β₁ = 81/0.85 = 95 mm`,
`c/d = 95/442 = 0.215 < 0.375` — হ্যাঁ, তাই `φ = 0.9` ঠিক আছে।

### ধাপ ৬ — চার bar এক সারিতে ধরে কি না

```
প্রয়োজনীয় প্রস্থ = 2×40 + 2×8 + 4×20 + 3×25 (ফাঁক) = 251 mm < 300  ✔
```

## অ্যাজাম্পশন

- Rectangular section, কোনো compression rod ধরা হয়নি।
- Normal-weight concrete, `β₁ = 0.85` (`f'c ≤ 28 MPa`)।
- Bar-এর মধ্যে ন্যূনতম ফাঁক ২৫ mm বা bar ব্যাস, যেটি বড়।

## Critical section

Shear-এর critical section support-এর মুখ থেকে **d** দূরে — ঠিক support-এ নয়,
কারণ ওই অংশ সরাসরি support-এ ভার দেয়।

## উদাহরণ

আগের বিম: `b` = ৩০০ mm, `d` = ৪৪২ mm, `f'c` = ২৫ MPa, stirrup `f_yt` = ৪২০ MPa।
Critical section-এ `V_u` = ১৯৫ kN।

### ধাপ ১ — কংক্রিটের অবদান

```
V_c = 0.17 √f'c × b × d = 0.17 × 5 × 300 × 442 / 1000 = 113 kN
φV_c = 0.75 × 113 = 85 kN
```

### ধাপ ২ — stirrup-এর ভাগ

```
V_u = 195 kN  >  φV_c = 85 kN  →  stirrup লাগবে
প্রয়োজনীয় φV_s = 195 − 85 = 110 kN
V_s = 110 / 0.75 = 147 kN
```

### ধাপ ৩ — ব্যবধান

দুই পায়ের ৮ mm stirrup: `A_v` = ২ × ৫০ = ১০০ mm²।

```
s = A_v f_yt d / V_s = 100 × 420 × 442 / (147 × 10³) = 126 mm
```

### ধাপ ৪ — সর্বোচ্চ ব্যবধানের সীমা

```
V_s = 147 kN  <  0.33 √f'c b d = 0.33 × 5 × 300 × 442/1000 = 219 kN
→ s_max = min(d/2, 600 mm) = min(221, 600) = 221 mm
```

126 < 221, তাই **৮ mm @ ১২৫ mm c/c** নেওয়া যায়।

### ধাপ ৫ — মাঝখানে

Mid-span-এ shear কম, সেখানে ন্যূনতম stirrup:

```
A_v,min = 0.062 √f'c × b × s / f_yt  →  s = 100 × 420 / (0.062 × 5 × 300) = 451 mm
s_max = d/2 = 221 mm  →  8 mm @ 200 mm c/c
```

## ব্যবহারিক নিয়ম

- Support-এর কাছে ২d দূরত্ব পর্যন্ত ঘন stirrup।
- প্রথম stirrup support-এর মুখ থেকে ৫০ mm-এ।
- ব্যবধান বদলানোর জায়গা ড্রয়িংয়ে স্পষ্ট করে লিখুন।

## সীমাবদ্ধতা

উপরের `V_c` সূত্র axial load ছাড়া সাধারণ বিমের। Axial টান থাকলে `V_c` কমে;
ভূমিকম্প-প্রতিরোধী ফ্রেমে আলাদা ও কঠোর ডিটেইলিং নিয়ম প্রযোজ্য।

## Curtailment কেন

Mid-span-এ যত rod লাগে, support-এর কাছে তত লাগে না। কিছু rod আগেই থামিয়ে
দেওয়া যায় — কিন্তু **কোথায় থামাবেন** তার নিয়ম আছে।

## নিয়ম

1. Rod যেখানে তাত্ত্বিকভাবে আর দরকার নেই, সেখান থেকে আরও **d** বা **12 d_b**
   (যেটি বড়) পর্যন্ত চালিয়ে যেতে হবে।
2. প্রতিটি rod-এর মোট দৈর্ঘ্য সর্বোচ্চ-moment বিন্দু থেকে অন্তত `l_d` হতে হবে।
3. Simply supported বিমে নিচের rod-এর অন্তত **এক-তৃতীয়াংশ** support পর্যন্ত
   যাবে।
4. Continuous বিমে উপরের rod-এর অন্তত **এক-তৃতীয়াংশ** inflection point ছাড়িয়ে
   `d`, `12 d_b` বা `l_n/16` — যেটি বড় — পর্যন্ত যাবে।

## ড্রয়িংয়ে যা থাকতে হবে

- বিম মার্ক (B1, B2…) ও schedule-এর সাথে মিল
- প্রস্থ × গভীরতা
- নিচের rod: সংখ্যা, ব্যাস, কোনটা কোথায় থামছে
- উপরের rod: সংখ্যা, ব্যাস, support-এর দুই পাশে দৈর্ঘ্য
- Stirrup: ব্যাস, ব্যবধান, কোন জোনে কোন ব্যবধান
- Section কাটা (support-এ একটি, mid-span-এ একটি)
- Cover

## কেন গুরুত্বপূর্ণ

Short কলাম উপাদানের strength-এ ব্যর্থ হয়। Slender কলাম তার আগেই **বেঁকে**
যায় — কম লোডেই। দুটির হিসাব সম্পূর্ণ আলাদা, তাই প্রথম কাজ ভাগ করা।

## Slenderness ratio

```
λ = k l_u / r
```

- `l_u` = কলামের unsupported দৈর্ঘ্য
- `k` = effective length factor (braced frame-এ সাধারণত ১.০)
- `r` = radius of gyration ≈ ০.৩ × আয়তাকার কলামের বাহু

## উদাহরণ

৩০০ × ৪৫০ mm কলাম, floor-to-floor ৩.২ m, বিমের গভীরতা ৫০০ mm, braced frame:

```
l_u = 3200 − 500 = 2700 mm
r = 0.3 × 300 = 90 mm      (দুর্বল অক্ষে)
λ = 1.0 × 2700 / 90 = 30
```

## সীমা

Braced frame-এ slenderness উপেক্ষা করা যায় যখন:

```
λ ≤ 34 − 12 (M1/M2)   এবং   λ ≤ 40
```

`M1/M2` = ছোট ও বড় প্রান্ত-moment-এর অনুপাত (single curvature-এ ধনাত্মক)।
ধরা যাক `M1/M2 = 0.5`:

```
সীমা = 34 − 12 × 0.5 = 28
λ = 30 > 28  →  slender, দ্বিতীয় ক্রমের প্রভাব ধরতে হবে
```

মাত্র সামান্য বেশি — কিন্তু নিয়ম নিয়মই। কলামের বাহু ৩৫০ mm করলে `r = 105`,
`λ = 26 < 28` → short হয়ে যায়।

## অ্যাজাম্পশন

- Braced (non-sway) frame ধরা হয়েছে। Sway frame-এ সীমা অনেক কম (λ ≤ 22)।
- `r = 0.3h` আয়তাকার প্রস্থচ্ছেদের আনুমানিক মান।

## ধারণা

কলামে axial load `P` আর moment `M` একসাথে থাকে। একটির ক্ষমতা অন্যটির উপর
নির্ভর করে — তাই একটিমাত্র সংখ্যা দিয়ে capacity বলা যায় না। Interaction
diagram হলো সব সম্ভাব্য `(P, M)` জোড়ার সীমারেখা।

## চারটি গুরুত্বপূর্ণ বিন্দু

| বিন্দু | অবস্থা |
| --- | --- |
| **Pure compression** | `M = 0`, সর্বোচ্চ axial ক্ষমতা |
| **Balanced point** | কংক্রিট চূর্ণ ও rod yield একসাথে ঘটে; সর্বোচ্চ moment ক্ষমতা |
| **Pure bending** | `P = 0`, বিমের মতো আচরণ |
| **Pure tension** | সব rod টানে |

## Pure compression ক্ষমতা

৩৫০ × ৩৫০ mm কলাম, ৮টি ২০ mm bar, `f'c` = ২৫ MPa, `f_y` = ৪২০ MPa:

```
A_g = 350 × 350 = 122,500 mm²
A_st = 8 × 314 = 2512 mm²
P_o = 0.85 f'c (A_g − A_st) + f_y A_st
    = 0.85 × 25 × (122500 − 2512) + 420 × 2512
    = 2,549,745 + 1,055,040 = 3,604,785 N ≈ 3605 kN

tied কলামে: φP_n,max = 0.80 × φ × P_o = 0.80 × 0.65 × 3605 = 1875 kN
```

`0.80` গুণক দুর্ঘটনাজনিত ন্যূনতম eccentricity ধরার জন্য — অর্থাৎ **কোনো
কলামই বিশুদ্ধ axial ধরা হয় না**।

## Balanced point-এর তাৎপর্য

Balanced point-এর **উপরে** (বেশি axial) কলাম চূর্ণ হয়ে ব্যর্থ হয় — হঠাৎ,
সতর্কতা ছাড়া। **নিচে** rod আগে yield করে — ধীর, দৃশ্যমান ফাটল সহ।

ডিজাইনে যথাসম্ভব balanced point-এর নিচে থাকা ভালো, কারণ সেই ব্যর্থতা
সতর্কবার্তা দেয়।

## ব্যবহারিক কথা

Interaction diagram হাতে আঁকা কষ্টসাধ্য। প্রচলিত অনুশীলনে প্রকাশিত chart বা
সফটওয়্যার ব্যবহার করা হয় — কিন্তু **উপরের চারটি বিন্দু হাতে যাচাই করতে পারা**
জরুরি, নইলে chart ভুল পড়লে ধরা পড়বে না।

## Longitudinal rod

- ন্যূনতম: `0.01 A_g`, সর্বোচ্চ: `0.08 A_g` (lap-এ `0.04` রাখলে কাজ সহজ)
- আয়তাকার কলামে অন্তত ৪টি bar, বৃত্তাকারে অন্তত ৬টি
- ৩৫০ × ৩৫০ কলামে: `A_s,min = 0.01 × 122500 = 1225 mm²` → ৪টি ২০ mm (১২৫৬ mm²)

## Tie (lateral) reinforcement

ব্যবধান তিনটির মধ্যে **সবচেয়ে ছোট**:

```
16 × longitudinal bar ব্যাস = 16 × 20 = 320 mm
48 × tie ব্যাস            = 48 × 8  = 384 mm
কলামের ছোট বাহু           =           350 mm
→ 320 mm, ব্যবহারিকভাবে 300 mm
```

Tie-এর কাজ শুধু rod ধরে রাখা নয় — এটি কংক্রিটকে ঘিরে রাখে (confinement) এবং
rod-কে বাইরে বেঁকে যাওয়া (buckling) থেকে বাঁচায়।

## Lap splice কোথায়

- **কলামের মাঝ-উচ্চতায়** — সেখানে moment সবচেয়ে কম
- **beam-column joint-এর ভেতরে নয়** — সেখানে ইতিমধ্যেই rod-এর ভিড়
- একই তলে সব rod-এর lap একসাথে নয়; stagger করুন
- Lap-এর দৈর্ঘ্য: compression lap সাধারণত `0.071 f_y d_b` (`f_y ≤ 420` MPa)

```
0.071 × 420 × 20 = 596 mm → 600 mm
```

## Dowel

ফুটিং থেকে কলামে ওঠা dowel-এর ফুটিংয়ে ঢোকার দৈর্ঘ্য compression development
length পূরণ করতে হবে, এবং উপরে কলামের rod-এর সাথে lap হবে।

## সবচেয়ে সাধারণ ভুল

Beam-column joint-এ tie বাদ দেওয়া। ঢালাইয়ের সময় জায়গা কম বলে শ্রমিক প্রায়ই
সেখানে tie দেয় না — অথচ ভূমিকম্পে joint-ই সবচেয়ে গুরুত্বপূর্ণ জায়গা।

## সীমাবদ্ধতা

উপরের মানগুলো সাধারণ (non-seismic) ডিটেইলিংয়ের। ভূমিকম্প-প্রতিরোধী ফ্রেমে
tie-এর ব্যবধান, hook-এর কোণ ও confinement zone-এর নিয়ম আলাদা ও কঠোর —
প্রকল্পে প্রযোজ্য কোডের বিধান দেখে নিন।

## দুই ধরনের চাপ

- **Active** — দেয়াল মাটি থেকে সামান্য সরে গেলে মাটি যে চাপ দেয়। সবচেয়ে কম।
- **Passive** — দেয়াল মাটির দিকে ঠেললে মাটি যে বাধা দেয়। সবচেয়ে বেশি।

রিটেইনিং ওয়ালের ডিজাইনে পেছনে **active** ধরা হয়, আর সামনের passive প্রায়ই
রক্ষণশীলভাবে উপেক্ষা করা হয় (মাটি সরে যেতে পারে)।

## Rankine সহগ

```
K_a = (1 − sin φ) / (1 + sin φ)
K_p = (1 + sin φ) / (1 − sin φ)
```

## উদাহরণ

- দেয়ালের উচ্চতা `H` = ৪.০ m
- ব্যাকফিল: দানাদার বালু, `φ` = ৩০°, `γ` = ১৮ kN/m³
- উপরে surcharge `q` = ১০ kPa
- Water table ব্যাকফিলের অনেক নিচে (drainage কাজ করছে)

### ধাপ ১ — সহগ

```
K_a = (1 − sin 30°) / (1 + sin 30°) = (1 − 0.5) / (1 + 0.5) = 0.333
```

### ধাপ ২ — মাটির চাপ

```
তলদেশে চাপ = K_a γ H = 0.333 × 18 × 4.0 = 24.0 kPa
বল P₁ = ½ × 24.0 × 4.0 = 48.0 kN/m       (তল থেকে 4.0/3 = 1.33 m উপরে)
```

### ধাপ ৩ — surcharge-এর চাপ

```
সমান চাপ = K_a q = 0.333 × 10 = 3.33 kPa
বল P₂ = 3.33 × 4.0 = 13.3 kN/m           (তল থেকে 2.0 m উপরে)
```

### ধাপ ৪ — মোট

```
P_a = 48.0 + 13.3 = 61.3 kN/m
```

## Water — সবচেয়ে বড় ঝুঁকি

Drainage ব্যর্থ হয়ে পানি জমলে হাইড্রোস্ট্যাটিক চাপ যোগ হয়:

```
তলদেশে পানির চাপ = γ_w H = 9.81 × 4.0 = 39.2 kPa
বল = ½ × 39.2 × 4.0 = 78.5 kN/m
```

মাটির চাপের চেয়ে **বেশি** — অর্থাৎ পানি জমলে মোট চাপ দ্বিগুণেরও বেশি হয়ে
যায়। বেশিরভাগ রিটেইনিং ওয়াল ব্যর্থতার মূল কারণ এটাই।

## অ্যাজাম্পশন

- Rankine তত্ত্ব: দেয়ালের পিঠ মসৃণ ও উল্লম্ব, ব্যাকফিলের উপরিতল সমতল।
- দানাদার ব্যাকফিল, `c = 0`। কাদামাটির ব্যাকফিলে এই হিসাব চলে না।
- Drainage কার্যকর — পরের লেসনে এটিই নিশ্চিত করার ব্যবস্থা দেখব।

| চেক | ন্যূনতম factor of safety |

## দেয়ালের জ্যামিতি

Cantilever T-wall: base প্রস্থ ২.৪ m, base পুরুত্ব ০.৪ m, stem পুরুত্ব ০.৩ m,
heel ১.৫ m, toe ০.৬ m, উচ্চতা ৪.০ m। কংক্রিটের `γ` = ২৪ kN/m³।

### ধাপ ১ — উল্লম্ব ওজন (প্রতি মিটারে)

```
Stem      : 0.3 × 3.6 × 24 = 25.9 kN   (toe প্রান্ত থেকে 0.75 m)
Base slab : 2.4 × 0.4 × 24 = 23.0 kN   (1.20 m)
Heel-এর মাটি : 1.5 × 3.6 × 18 = 97.2 kN (1.65 m)
মোট W = 146.1 kN
```

### ধাপ ২ — Overturning

Toe প্রান্তের সাপেক্ষে:

```
উল্টানোর moment = 48.0 × 1.33 + 13.3 × 2.0 = 63.8 + 26.6 = 90.4 kN·m
প্রতিরোধী moment = 25.9×0.75 + 23.0×1.20 + 97.2×1.65
                 = 19.4 + 27.6 + 160.4 = 207.4 kN·m
FS = 207.4 / 90.4 = 2.29  ≥ 2.0  ✔
```

### ধাপ ৩ — Sliding

Base-মাটির ঘর্ষণ কোণ `δ = 2φ/3 = 20°` ধরে:

```
প্রতিরোধী বল = W tan δ = 146.1 × tan 20° = 146.1 × 0.364 = 53.2 kN
FS = 53.2 / 61.3 = 0.87  <  1.5  ✘  ব্যর্থ
```

**Sliding-ই নিয়ন্ত্রক** — এবং প্রথম চেষ্টায় প্রায়ই ব্যর্থ হয়।

সমাধানের পথ: base প্রশস্ত করা, অথবা base-এর নিচে একটি **shear key** দেওয়া।
০.৪ m গভীর key দিলে সামনের passive প্রতিরোধ যোগ হয়:

```
K_p = 3.0
passive বল ≈ ½ K_p γ D² = ½ × 3.0 × 18 × 0.4² = 4.3 kN   (সামান্য)
```

তার চেয়ে কার্যকর: base ২.৪ → ৩.২ m করা, যাতে heel-এর মাটির ওজন বাড়ে।

### ধাপ ৪ — Bearing

```
নিট moment = 207.4 − 90.4 = 117.0 kN·m
x̄ = 117.0 / 146.1 = 0.80 m  (toe থেকে)
e = B/2 − x̄ = 1.2 − 0.80 = 0.40 m
B/6 = 0.40  →  e = B/6, ঠিক সীমায় — resultant middle third-এর প্রান্তে
q_max = W/B × (1 + 6e/B) = 60.9 × 2 = 121.8 kPa
```

মাটির allowable bearing capacity এর চেয়ে বেশি হতে হবে।

## গুরুত্বপূর্ণ

`e > B/6` হলে base-এর একাংশে টান আসে — মাটি টান নেয় না, তাই ওই অংশ ফাঁকা হয়ে
যায় এবং বাকি অংশে চাপ অনেক বেড়ে যায়। এটি এড়াতে হবে।

## কেন সবার আগে

আগের লেসনে দেখলাম, পানি জমলে চাপ প্রায় দ্বিগুণ হয়ে যায় — অথচ কোনো ডিজাইনেই
সাধারণত সেই চাপ ধরা হয় না। তাই drainage কোনো "অতিরিক্ত সুবিধা" নয়, এটি
ডিজাইনের একটি **অনুমান** যা বাস্তবে নিশ্চিত করতে হয়।

## ব্যবস্থা

**১. Weep hole**
- ৭৫ mm PVC পাইপ
- আনুভূমিক ও উল্লম্ব উভয় দিকে ১.৫–২.০ m ব্যবধানে
- সর্বনিম্ন সারি মাটির উপরিতল থেকে ৩০০ mm উপরে
- ভেতরের মুখে filter media, যাতে সূক্ষ্ম কণা বেরিয়ে না যায়

**২. Granular backfill**
- দেয়ালের পেছনে অন্তত ৩০০ mm পুরু পরিষ্কার খোয়া বা মোটা বালু
- কাদামাটি সরাসরি দেয়ালের পিঠে নয় — কাদা পানি ধরে রাখে ও ফুলে ওঠে

**৩. Perforated drain pipe**
- Heel বরাবর ১০০ mm ছিদ্রযুক্ত পাইপ, ঢাল সহ
- চারপাশে geotextile filter
- নির্দিষ্ট আউটলেটে গিয়ে শেষ হবে — নইলে পাইপ নিজেই জলাধার হয়ে যায়

**৪. উপরিতলে সিল**
- উপরের ৩০০ mm-এ কম প্রবেশযোগ্য মাটি, যাতে বৃষ্টির পানি সরাসরি না ঢোকে
- উপরিতলে দেয়াল থেকে দূরে ঢাল

## অন্যান্য ডিটেইল

- **Expansion joint:** প্রতি ২০–৩০ m-এ
- **Contraction joint:** প্রতি ৬–৯ m-এ
- **Stem-এর rod:** পেছনের দিকে (মাটির দিকে) — সেখানেই টান
- **Cover:** মাটির সংস্পর্শে ৫০–৭৫ mm

## রক্ষণাবেক্ষণ

Weep hole বছরে অন্তত একবার পরীক্ষা করা দরকার। বন্ধ weep hole মানে ডিজাইনের
অনুমান আর সত্য নয় — দেয়ালটি তখন যে চাপের জন্য তৈরি হয়নি সেই চাপে আছে।

## মৌলিক নিয়ম

```
2 × rise + tread = 600 থেকে 640 mm
```

এটি মানুষের স্বাভাবিক পদক্ষেপের দৈর্ঘ্য থেকে আসা একটি ব্যবহারিক নিয়ম।

## প্রচলিত মান

| ব্যবহার | Rise (mm) | Tread (mm) |
| --- | --- | --- |
| আবাসিক | ১৫০–১৭৫ | ২৫০–৩০০ |
| অফিস ও পাবলিক | ১৪০–১৬০ | ২৮০–৩০০ |
| খাড়া/সেবা সিঁড়ি | ১৭৫–১৯০ | ২২৫–২৫০ |

## উদাহরণ

Floor-to-floor উচ্চতা ৩.২ m, dog-legged সিঁড়ি:

```
ধরা যাক rise ≈ 160 mm
ধাপের সংখ্যা = 3200 / 160 = 20 টি
প্রকৃত rise = 3200 / 20 = 160 mm  ✔
প্রতি ফ্লাইটে ধাপ = 10 টি (দুই ফ্লাইট)

tread = 620 − 2 × 160 = 300 mm
```

যাচাই: `2 × 160 + 300 = 620` ✔ (৬০০–৬৪০-এর মধ্যে)

## ফ্লাইটের অনুভূমিক দৈর্ঘ্য

একটি ফ্লাইটে ১০টি rise কিন্তু **৯টি tread** — শেষ ধাপটি landing:

```
going = 9 × 300 = 2700 mm
```

## Landing

- প্রস্থ ফ্লাইটের প্রস্থের চেয়ে কম নয়, সাধারণত ১.২–১.৫ m
- এক ফ্লাইটে সর্বোচ্চ ১২–১৬ ধাপ; বেশি হলে মাঝে landing

## Headroom

যেকোনো ধাপের নাক থেকে উপরের কাঠামো পর্যন্ত উল্লম্ব ফাঁক অন্তত **২.০ m** —
dog-legged সিঁড়িতে নিচের ফ্লাইটের উপর দিয়ে যাওয়ার সময় এটি প্রায়ই কমে যায়,
তাই আলাদা করে যাচাই করুন।

## সমস্যাটা

Waist slab ঢালু, কিন্তু লোড হিসাব হয় **অনুভূমিক** প্রক্ষেপণের উপর। ঢালু
দৈর্ঘ্য অনুভূমিকের চেয়ে বেশি — তাই waist slab-এর ওজন সেই অনুপাতে বাড়াতে হয়।

## ধাপে ধাপে

আগের সিঁড়ি: rise ১৬০, tread ৩০০, waist slab ১৫০ mm।

### ধাপ ১ — ঢালু সংশোধনী

```
ঢালু দৈর্ঘ্য / অনুভূমিক = √(R² + T²) / T = √(160² + 300²) / 300
                        = √(25600 + 90000) / 300 = 340 / 300 = 1.133
```

### ধাপ ২ — Waist slab-এর ওজন

```
প্রতি m² ঢালু তলে = 0.15 × 24 = 3.60 kPa
অনুভূমিকে         = 3.60 × 1.133 = 4.08 kPa
```

### ধাপ ৩ — ধাপের (step) ওজন

ত্রিভুজাকার ধাপের গড় পুরুত্ব = rise/2:

```
= (0.160 / 2) × 24 = 1.92 kPa
```

### ধাপ ৪ — ফিনিশ

```
= 1.00 kPa (টাইলস ও মর্টার)
```

### ধাপ ৫ — মোট dead load

```
D = 4.08 + 1.92 + 1.00 = 7.00 kPa
```

### ধাপ ৬ — Live load ও factored

```
L = 3.0 kPa (আবাসিক সিঁড়ি)
w_u = 1.2 × 7.00 + 1.6 × 3.0 = 8.40 + 4.80 = 13.2 kPa
```

## গুরুত্বপূর্ণ

Landing-এ ঢালু সংশোধনী **লাগে না** (সমতল), কিন্তু live load একই। তাই
landing-এ `D = 0.15 × 24 + 1.0 = 4.60 kPa` — ফ্লাইটের চেয়ে কম।

সরলতার জন্য অনেকে পুরো span জুড়ে ফ্লাইটের বেশি লোড ধরেন — রক্ষণশীল, এবং
হাতে হিসাবের জন্য গ্রহণযোগ্য।

## Span কোথা থেকে

Dog-legged সিঁড়িতে waist slab দুই landing beam-এর মধ্যে one-way slab হিসেবে
কাজ করে।

```
কার্যকর span = going + দুই পাশের landing-এর অর্ধেক
             = 2.70 + 1.20/2 + 1.20/2 = 3.90 m
```

## Moment

Simply supported ধরে (রক্ষণশীল):

```
M_u = w_u l² / 8 = 13.2 × 3.90² / 8 = 13.2 × 15.21 / 8 = 25.1 kN·m/m
```

## Effective depth

```
d = 150 − 20 (cover) − 12/2 = 124 mm
```

## Main rod

```
A_s = M_u / (φ f_y × 0.95d)
    = 25.1 × 10⁶ / (0.9 × 420 × 0.95 × 124)
    = 25.1 × 10⁶ / 44,528
    ≈ 564 mm²/m
```

ন্যূনতম যাচাই:

```
A_s,min = 0.0018 × 1000 × 150 = 270 mm²/m   ✔ (564 > 270)
```

Bar নির্বাচন:

```
১২ mm bar = 113 mm²
ব্যবধান = 113 / 564 × 1000 = 200 mm
→ 12 mm @ 200 mm c/c (ঢালু বরাবর, নিচে)
```

## Distribution rod

```
A_s,dist = 0.0018 × 1000 × 150 = 270 mm²/m
→ 10 mm @ 250 mm c/c (আড়াআড়ি)
```

## Top rod

Support-এর কাছে (landing beam-এর মুখে) hogging moment হয়। বাস্তবে সংযোগ
আংশিকভাবে fixed, তাই main rod-এর অন্তত অর্ধেক পরিমাণ top rod দিন, support
থেকে span-এর প্রায় এক-চতুর্থাংশ পর্যন্ত।

## সবচেয়ে গুরুত্বপূর্ণ ডিটেইল

**ভাঁজের ভেতরের দিকে rod রাখা যাবে না।** সিঁড়ি ও landing-এর সংযোগে ভেতরের
কোণে rod থাকলে টানের ফলে rod কংক্রিট ছিঁড়ে বেরিয়ে আসতে চায়। rod দুটিকে
আলাদা করে **বাইরের দিক দিয়ে** ঘুরিয়ে যথাযথ development length পর্যন্ত
নিতে হয়। এটি সিঁড়ির ডিটেইলিংয়ের সবচেয়ে সাধারণ ও বিপজ্জনক ভুল।

## অ্যাজাম্পশন

- Simply supported ধরা হয়েছে; continuity ধরলে moment কমত।
- `jd = 0.95d` প্রথম-চেষ্টা অনুমান।
- Waist slab দুই প্রান্তে beam-এ বসছে; wall-এ বসলে span আলাদা।
